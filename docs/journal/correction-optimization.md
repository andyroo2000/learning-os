# Compact corrections and prepared feedback

The model and reasoning effort remain configured by `journal.model` and `journal.reasoning_effort`. The full existing teaching instructions remain in use. A serialization contract asks for annotated text once; the server derives plain counterparts, concatenates exact replacements for the final version, and runs the existing full validation. Suggestions remain full sentences; explanations are not shortened. Optional suggestions stay unapplied. Existing web/iOS response fields are unchanged.

The meaning-check request can return compact feedback when resolved. It still returns only a clarification question while meaning is uncertain. Prepared feedback is stored privately on the clarification row, under the same draft revision/attempt fences. Explicit submission publishes it through the existing analysis flow, including title and tutor question creation. The analysis rechecks clarification state, original source and conversation-context hash before reuse; older meaning-only rows or changed context take the ordinary feedback path. No provider call runs under a journal write lock.

Prompt cache keys separate feedback and combined requests. Cache hits remain provider-controlled, and measured cached/write tokens are reported by the usage ledger. Do not interpret cache keys as guaranteed discounts.

Validation includes exact whitespace/emoji preservation, complete furigana, optional corrections, deletion spans, source mismatch rejection, unresolved-feedback rejection, unchanged client payloads, duplicate jobs, changed drafts, and changed conversation context. Live A/B checks used the same production model/effort against synthetic entries: spelling, acceptable casual prose, literal movie title, ambiguous actors, and clarified actors. Both flows asked who was driving before correcting and retained separate subjects after confirmation. Clear entries used one request instead of two. Measured costs varied with cache warmth and reasoning; these small examples are not a forecast of subscriber margins.
